# Cube Solver Lab

Программа для сборки головоломок, которая целиком работает в браузере: кубики от 2×2 до 15×15, Пирамидка (Pyraminx) и Скьюб (Skewb). Рядом с 3D-кубиком показан граф перестановок: каждая наклейка — это узел, и видно, как каждый поворот двигает наклейки по окружностям.

**Сайт: https://cube-solver.org**

## Возможности

- **Решение** кубиков от 2×2 до 15×15, Пирамидки и Скьюба. Для 2×2, Пирамидки и Скьюба находятся оптимальные решения. Для 3×3 используется двухфазный алгоритм Коцембы (обычно 19–21 ход). Для 5×5 и больше — gullicube, скомпилированный в многопоточный WebAssembly.
- **Ввод позиции**: раскраска развёртки, ввод скрамбла (`R U R' U2 …`, включая широкие повороты и повороты среднего слоя), сканирование камерой или загрузка фотографий.
- **Проверка**, которая объясняет, что не так: не хватает цветов, повёрнут угол, перевёрнуто ребро, нарушена чётность и т. д.
- **Пошаговый просмотр** с временной шкалой, регулировкой скорости и горячими клавишами; 3D-вид и граф анимируются синхронно.
- **Свободная игра** на кубиках от 2×2 до 15×15: поворачивайте слои мышью, касанием или с клавиатуры; есть таймер, необязательный осмотр по правилам WCA, отмена/повтор и лучшие результаты.
- **12 языков**, для арабского — полная вёрстка справа налево, а также отдельная статическая страница для поисковиков для каждой головоломки на каждом языке.
- **Синтезированный звук**: все звуки создаются на лету через Web Audio API, аудиофайлов в проекте нет.

## Конфиденциальность

- Изображение с камеры и загруженные фотографии обрабатываются только в вашем браузере. Они никуда не отправляются и не хранятся на сервере.
- Опубликованный сайт считает посещения с помощью Cloudflare Web Analytics: он не использует cookie и не собирает персональные данные, поэтому загружается для всех посетителей. Google Analytics 4 загружается только после нажатия «Принять» в баннере согласия (Consent Mode v2; хранение рекламных данных, рекламные пользовательские данные, персонализация рекламы и Google Signals отключены). Если вы откажетесь, он не загружается вовсе, а изменить выбор можно в любой момент по ссылке «Настройки аналитики» в подвале сайта. Настройки (язык, звук, лучшие результаты, выбор по аналитике) хранятся только в локальном хранилище вашего браузера. Аналитика считает только просмотры страниц: состояния головоломок и изображения с камеры никогда не отправляются.
- Сайт — это набор статических файлов на хостинге Cloudflare, который, как и любой хостинг, обрабатывает обычные веб-запросы.

## Локальный запуск

Требуется Node.js 18 или новее.

```bash
npm install
npx playwright install chromium   # нужно только для браузерных тестов
npm start                         # http://localhost:8765/
```

Камере нужен безопасный контекст (`https://` или `http://localhost`). Локальный сервер отправляет те же заголовки межсайтовой изоляции, что и рабочий сайт, — без них многопоточный WebAssembly не работает.

## Тесты

```bash
npm test               # собирает SEO-страницы, затем запускает модульные тесты, тесты решателей и SEO (браузер не нужен)
npm run test:nxn       # проверка решателей 4×4–15×15 (дольше)
npm start &            # браузерным тестам нужен локальный сервер
npm run test:e2e       # а также: test:i18n, test:play, test:twisty, test:naming, test:analytics
```

## Сборка и публикация

```bash
npm run build          # собирает готовый к публикации сайт в dist/
```

Сайт публикуется как статические ресурсы Cloudflare Workers (см. `deploy/`):

```bash
export CLOUDFLARE_ACCOUNT_ID=<ID вашего аккаунта>
export CLOUDFLARE_API_TOKEN=<API-токен с правом изменять Workers>   # или выполните: npx wrangler login
export CF_BEACON_TOKEN=<token>               # необязательно: токен Cloudflare Web Analytics
export GA_MEASUREMENT_ID=G-XXXXXXXXXX        # необязательно: идентификатор GA4, загружается только после согласия
npm run deploy
```

- `deploy/_headers` задаёт `Cross-Origin-Opener-Policy` и `Cross-Origin-Embedder-Policy`, которые нужны многопоточному решателю на WebAssembly.
- `deploy/worker.js` только перенаправляет: `www` и `*.workers.dev` — на основной домен, старые ссылки `/?puzzle=…` — на новые адреса. Статические файлы (`/js`, `/css`, `/img`, `/puzzles`, `/vendor` и т. д.) отдаются напрямую, без запуска Worker, поэтому один просмотр страницы — это один запрос к Worker.
- Идентификаторов аналитики в репозитории нет. `npm run build` берёт `CF_BEACON_TOKEN` и `GA_MEASUREMENT_ID` из окружения (или из игнорируемого git файла `.env` со строками `KEY=value`) и записывает их только в `dist/`. Если они не заданы, в сборке нет ни аналитики, ни баннера согласия, ни отслеживания; кроме того, аналитика работает только на основном домене.
- Если вы публикуете свою копию, измените `name` и `routes` в `deploy/wrangler.toml` и `baseUrl` в `seo/site.config.json`.

Заметки для разработчиков (на китайском): [docs/DEVELOPMENT.zh-Hans.md](docs/DEVELOPMENT.zh-Hans.md).
