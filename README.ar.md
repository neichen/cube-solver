# Cube Solver Lab

أداة لحلّ الألغاز تعمل بالكامل داخل متصفحك: مكعبات من 2×2 إلى 15×15، والبيرامنكس (Pyraminx) والسكيوب (Skewb) والميغامينكس (Megaminx). بجانب النموذج ثلاثي الأبعاد يظهر مخطط تباديل يمثّل كل ملصق بعقدة، فترى كيف تحرّك كل لفّة الملصقات على طول دوائر.

**الموقع: https://cube-solver.org**

## الميزات

- **الحل** لمكعبات من 2×2 إلى 15×15 والبيرامنكس والسكيوب والميغامينكس. يحصل 2×2 والبيرامنكس والسكيوب على حلول مثلى. يستخدم 3×3 خوارزمية كوتسيمبا ذات المرحلتين (عادةً 19–21 حركة). ولمكعبات 5×5 فأكبر يُستخدم gullicube مترجَمًا إلى WebAssembly متعدد الخيوط. ويستخدم الميغامينكس طريقة سريعة متعددة المراحل (نحو 120 حركة HTM في المتوسط، وليست مثلى).
- **إدخال الوضع** بتلوين مخطط المكعب المفرود، أو كتابة خلطة (`R U R' U2 …` مع الحركات العريضة وحركات الطبقة الوسطى)، أو المسح بالكاميرا، أو رفع الصور.
- **تحقق** يشرح موضع الخطأ: ألوان ناقصة، أو زاوية ملتوية، أو حافة مقلوبة، أو خطأ في التكافؤ وغير ذلك.
- **مشغّل خطوة بخطوة** مع شريط زمني وتحكم في السرعة واختصارات لوحة المفاتيح، متزامن بين العرض ثلاثي الأبعاد والمخطط.
- **لعب حر** على جميع الألغاز: لُفّ الطبقات بالسحب أو بلوحة المفاتيح، مع مؤقت وفحص WCA اختياري وتراجع/إعادة وأفضل الأزمنة. يتبع خلط الميغامينكس أسلوب WCA (Pochmann).
- **12 لغة**، مع تخطيط كامل من اليمين إلى اليسار للعربية، وصفحة ثابتة مهيأة لمحركات البحث لكل لغز بكل لغة.
- **صوت مُركَّب**: تُولَّد كل الأصوات مباشرةً عبر Web Audio API، ولا يتضمن المشروع أي ملفات صوتية.

## الخصوصية

- تُعالَج صور الكاميرا والصور المرفوعة داخل متصفحك فقط، ولا تُرفع إلى أي خادم ولا تُخزَّن عليه.
- يحصي الموقع المباشر الزيارات باستخدام Cloudflare Web Analytics، الذي لا يستخدم ملفات تعريف الارتباط ولا يجمع بيانات شخصية، ويُحمَّل لجميع الزوار. أما Google Analytics 4 فيعمل دائمًا بوضع Consent Mode v2 مع إيقاف تخزين الإعلانات وبيانات المستخدم الإعلانية وتخصيص الإعلانات وإشارات Google. في الاتحاد الأوروبي/المنطقة الاقتصادية الأوروبية والمملكة المتحدة وسويسرا (وعندما يتعذّر تحديد البلد) لا يُحمَّل إلا بعد أن تضغط «قبول» في شريط الموافقة؛ وفي غيرها لا يظهر الشريط ويُحمَّل لإحصاءات مشاهدات الصفحات فقط. وفي الحالتين يمكنك تشغيله أو إيقافه في أي وقت عبر رابط «إعدادات التحليلات» في تذييل الصفحة؛ ويؤدي «رفض» إلى إيقافه وحذف ملفات تعريف الارتباط الخاصة به. تُحفظ الإعدادات مثل اللغة والصوت وأفضل الأزمنة واختيارك للتحليلات في التخزين المحلي لمتصفحك فقط. لا تحصي التحليلات سوى مشاهدات الصفحات، ولا تُرسَل حالات الألغاز أو صور الكاميرا أبدًا.
- الموقع مجموعة من الملفات الثابتة مستضافة على Cloudflare، التي تعالج طلبات الويب العادية كأي مزوّد استضافة.

## التشغيل محليًا

المتطلبات: Node.js 18 أو أحدث.

```bash
npm install
npx playwright install chromium   # مطلوب لاختبارات المتصفح فقط
npm start                         # http://localhost:8765/
```

تحتاج الكاميرا إلى سياق آمن (`https://` أو `http://localhost`). يرسل الخادم المحلي ترويسات العزل عبر المصادر نفسها التي يرسلها الموقع المنشور، وهي لازمة لـ WebAssembly متعدد الخيوط.

## الاختبارات

```bash
npm test               # يبني صفحات SEO ثم يشغّل اختبارات الوحدات والحلول وSEO (دون متصفح)
npm run test:nxn       # فحص حلول 4×4–15×15 (أبطأ)
npm start &            # تحتاج اختبارات المتصفح إلى الخادم المحلي
npm run test:e2e       # وأيضًا: test:i18n, test:play, test:twisty, test:naming, test:analytics
```

## البناء والنشر

```bash
npm run build          # يجمع الموقع الجاهز للنشر في dist/
```

يُنشر الموقع كأصول ثابتة على Cloudflare Workers (راجع `deploy/`):

```bash
export CLOUDFLARE_ACCOUNT_ID=<معرّف حسابك>
export CLOUDFLARE_API_TOKEN=<رمز API يملك صلاحية تعديل Workers>   # أو شغّل: npx wrangler login
export CF_BEACON_TOKEN=<token>               # اختياري: رمز Cloudflare Web Analytics
export GA_MEASUREMENT_ID=G-XXXXXXXXXX        # اختياري: معرّف القياس لـ GA4، لا يُحمَّل إلا بعد الموافقة
npm run deploy
```

- يضبط `deploy/_headers` الترويستين `Cross-Origin-Opener-Policy` و`Cross-Origin-Embedder-Policy` اللتين يحتاجهما حلّال WebAssembly متعدد الخيوط.
- يقتصر عمل `deploy/worker.js` على إعادة التوجيه: من `www` و`*.workers.dev` إلى النطاق الرئيسي، ومن الروابط القديمة `/?puzzle=…` إلى المسارات الجديدة. تُقدَّم الملفات الثابتة (`/js` و`/css` و`/img` و`/puzzles` و`/vendor` وغيرها) مباشرةً دون تشغيل الـ Worker، لذا تكلّف مشاهدة الصفحة طلبًا واحدًا للـ Worker.
- معرّفات التحليلات ليست في المستودع. يقرأ `npm run build` المتغيرين `CF_BEACON_TOKEN` و`GA_MEASUREMENT_ID` من البيئة (أو من ملف `.env` يتجاهله git، بأسطر `KEY=value`) ويكتبهما في `dist/` فقط. إذا لم يُضبطا فلن يحتوي الناتج على أي تحليلات أو شريط موافقة أو تتبع؛ كما أن التحليلات لا تعمل إلا على نطاق الإنتاج.
- إذا نشرت نسختك الخاصة، فغيّر `name` و`routes` في `deploy/wrangler.toml` و`baseUrl` في `seo/site.config.json`.
